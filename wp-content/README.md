# WordPress Boilerplate Theme

This is a Wordpress boilerplate theme designed for developers to kickstart website projects. It includes a page builder, a hero header builder (managed via ACF fields), and a pre-configured Gulp workflow for compiling styles and scripts.

## Features

- **Custom Templates**: Includes templates for pages, blocks, and headers.
- **ACF Integration**: Uses Advanced Custom Fields Pro (v3+) for building hero headers and managing page content.
- **SASS Support**: Modular styling with SASS organized by components and blocks.
- **Gulp Workflow**: Automated tasks for compiling, minifying, and optimizing styles and scripts.
- **Organized Structure**: Theme files organized with `src/` for source files and `dist/` for compiled assets.
- **Custom Post Types**: Support for custom post types and taxonomies via ACF configuration.

## File Structure

```
|-- theme-folder/
    |-- includes/
        |-- acf-json/           # ACF field configurations
            |-- field-groups/   # ACF field group configurations
            |-- options-pages/  # ACF options page configurations
    |-- src/
        |-- fonts/              # Custom fonts
        |-- images/             # Image assets
        |-- js/                 # Custom JavaScript files
        |-- scss/               # Source SASS files
            |-- blocks/         # Block-specific styles
            |-- components/     # Component styles
            |-- admin/          # Admin-specific styles
            |-- defaults/       # Base and default styles
    |-- dist/                   # Compiled CSS and JS files (generated by Gulp)
    |-- functions/              # Custom WordPress functions
        |-- acf.php             # ACF-related functions
        |-- components.php      # Component helper functions
        |-- cpt.php             # Custom post types
        |-- helpers.php         # Utility helper functions
        |-- menu.php            # Menu configuration
        |-- setup.php           # Theme setup functions
    |-- templates/              # Header and block templates
        |-- blocks/             # Block template files
        |-- headers/            # Hero header template files
    |-- gulpfile.js             # Gulp configuration file
    |-- package.json            # Node dependencies
```

## Initial Installation

1. Start with a fresh blank WordPress installation either in WPLocal or on a local server.
2. Navigate to the `wp-content` directory
3. Create a .gitignore file locally and copy and paste the example from the repo.
4. Create a Git remote with the following commands:

   ```bash
   git init
   ```

   ```bash
   git remote add origin 
   ```
   
5. Once remote added use Git fetch to pull all repo data. There will be multiple branches available (main, staging, etc.).

   ```bash
   git fetch
   ```

6. Pull the main branch:

   ```bash
   git pull origin main
   ```

7. Make sure all code is correct and create a new branch to begin development:

   ```bash
   git checkout -b NEW-BRANCH-NAME
   ```

8. Activate the theme from the WordPress admin dashboard.

## Using Gulp

This theme uses Gulp to manage assets. The following tasks are included:

- **SASS Compilation**: Converts `.scss` files in `src/scss/` to CSS in `dist/css/`.
- **CSS Minification**: Minifies compiled CSS files.
- **JavaScript Concatenation**: Combines JS files from `src/js/` into `dist/js/scripts.min.js`.
- **File Watching**: Automatically watches for changes in SASS and JS files.

### Running Gulp

1. Ensure you have Gulp CLI installed globally:

   ```bash
   npm install -g gulp-cli
   ```

2. Navigate to the theme directory:

   ```bash
   cd wp-content/themes/essenta-theme
   ```

3. Run the default Gulp task:

   ```bash
   gulp
   ```

   This will:

   - Compile SASS to CSS.
   - Minify CSS.
   - Concatenate and optimize JavaScript.
   - Watch for file changes.

4. Gulp will continue running in the terminal, monitoring for changes to `.scss` and `.js` files. To stop, press `Ctrl + C`.

## Homepage Hero Video

On desktop (above 980px), scrolling down expands the homepage hero video into
full view. It starts playing and holds that view for three seconds before normal
page scrolling resumes. Scroll input during the pause is not queued; scroll
again after the pause to continue. Scrolling upward cancels the pause immediately
and reverses the expansion. Mobile retains normal scrolling without the pause.
The duration is controlled by `fullViewPauseMs` in `src/js/scripts.js`.

## Mobile Expandable Content

Add `class="expand"` to a text container (for example, a `div`, `p`, or
`section`) to show the first 30 words followed by `...` and a **Read more**
button at viewport widths of 767px or below. Shorter content is left unchanged.

**Read more** restores the original content, including its HTML, event listeners,
and form state; **Read less** returns to the plain-text preview. At 768px and
above, the full original content is shown without a toggle. Returning to mobile
resets the preview. The toggle inherits the container's font and colour.
Expanding and collapsing animate the container's height over 350ms, unless the
visitor has enabled reduced motion. The container returns to its natural height
after the animation so content is not left clipped.

Apply the class to the outermost container you want to shorten; nested `.expand`
elements are covered by that outer container rather than creating extra toggles.

## Sectors Module

The sectors module displays up to four cards in a two-column grid (at most two
rows) on desktop. When the combined number of queried and manual
sectors exceeds four, it becomes a two-row Slick slider with two full columns
and approximately a third of the next column visible. Cards fill each column
from top to bottom in their original list order.

Swipe or drag to move one two-card column at a time, without arrows or dots.
On mobile (760px and below), all lists use a single-row Slick slider showing
1.25 cards and moving one card at a time. Resizing across the breakpoint
rebuilds the layout using the original cards.
The focused module also accepts Left/Right arrow keys. Each slider stops at the
end of its list and respects reduced-motion preferences. Without JavaScript,
the horizontal list still scrolls natively.

## Development Workflow

1. **Set Up**:

   - Install dependencies with `npm install` in the theme directory.
   - Run the Gulp process to start asset compilation and file watching.

2. **Add Custom Styles**:

   - Write your styles in the `src/scss/` directory, organizing by component or block.
   - Changes will be automatically compiled to `dist/css/` by Gulp.

3. **Add Custom JavaScript**:

   - Add your scripts to `src/js/`.
   - Gulp will concatenate and minify them into `dist/js/scripts.min.js`.

4. **Create Custom Templates**:
   - Create or modify templates in the `templates/blocks/` folder.
   - Update header designs in the `templates/headers/` folder.

5. **ACF Field Management**:
   - Configure fields in the WordPress admin using ACF Pro.
   - Export field groups to `includes/acf-json/` via ACF's "Sync" feature.
   - Commit the JSON files to version control.
